01 / ABOUT THE PROJECT

What is this project about?

Forest fires are influenced by several environmental factors, including temperature, relative humidity, wind speed and rainfall. This project uses the Algerian Forest Fires Dataset to explore the relationship between these factors and forest fire occurrence through Machine Learning. The objective is to build a prediction model that learns patterns from historical meteorological data and generates predictions based on provided inputs.

02 / DATASET OVERVIEW

About the Dataset

The dataset contains 244 instances collected from two different regions of Algeria during the period of June 2012 to September 2012.

Bejaia Region

Located in northeastern Algeria. The dataset contains 122 instances from this region.

Sidi Bel-Abbes Region

Located in northwestern Algeria. The dataset contains 122 instances from this region.

Dataset Statistics

  • Total observations: 244
  • Fire cases: 138
  • Not Fire cases: 106
  • Number of input attributes: 11
  • Output attribute: Class
  • Collection period: June – September 2012
